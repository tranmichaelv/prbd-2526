# ReserVite — Application de gestion de réservations de restaurants

# Projet PRBD 2526 - Groupe c03
  
Projet de groupe réalisé à l'EPFC dans le cadre du cours « Projet de développement – Système de Gestion de Base de Données » (2025–2026).

# Présentation du projet

ReserVite est une application développée avec Flutter permettant aux clients de rechercher des restaurants et de gérer leurs réservations, tandis que les gestionnaires peuvent gérer leurs restaurants, leurs services, leurs tables et les réservations. Cette application peut e

Le projet utilise une base de données préexistante et un backend PostgREST. Des règles métier et des droits d'accès spécifiques sont imposés.

# Technologies utilisées
Flutter / Dart : développement de l'application.
Riverpod : gestion de l'état et synchronisation des données entre les écrans.
PostgREST / PostgreSQL : communication avec le backend et accès aux données via une API REST.

# Fonctionnalités principales
Authentification et gestion des rôles client et gestionnaire.
Recherche de restaurants et consultation de leurs détails.
Création, modification et annulation de réservations.
Gestion des réservations côté gestionnaire : confirmation, attribution des tables et finalisation.
Gestion des services d'ouverture et des tables des restaurants.
Respect des règles métier, des disponibilités et des autorisations.
Gestion du temps simulé
